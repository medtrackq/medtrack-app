🩺 เครื่องมือตรวจสอบ LINE เตือนยา

ไล่หาสาเหตุ "LINE ไม่เด้ง" ได้เองก่อนถาม user — ตัดปัญหาทีละข้อ

⚙️ ตั้งค่าการเชื่อมต่อ

URL ของ backend บน Railway (ไม่ต้องมี / ท้าย)

ดูใน Railway → Variables → SCHEDULER_TRIGGER_SECRET (กดที่ ***** เพื่อ reveal)

1️⃣ เช็ก Server + Quota

ตรวจว่า server ยังรัน และ quota limit ถูกต้อง (ควรเป็น 15000 ไม่ใช่ 500)

2️⃣ เช็ก User รายคน

เมื่อ user แจ้งว่าไม่ได้รับเตือน — เช็กว่าผูก LINE ไหม มียาไหม เตือนล่าสุดเมื่อไหร่

3️⃣ ยิง Scheduler เดี๋ยวนี้

จำลอง "ถึงเวลารอบ scheduler" ทันที — ส่งการ์ดของมื้อที่ถึงเวลาตอนนี้ (ต้องใส่ Secret ด้านบน)

📋 เช็กลิสต์เมื่อ "LINE ไม่เด้ง"

  • Server ยังรันอยู่ (Test 1 ผ่าน)
  • Quota ยังไม่เต็ม + limit = 15000 (Test 1)
  • User มี line_user_id (Test 2)
  • User มียาที่ยัง active (Test 2)
  • มี push log ส่งสำเร็จล่าสุด (Test 2)

ถ้าทุกข้อผ่านแต่ user ยังไม่ได้รับ: user อาจบล็อก/ลบ OA, ปิดแจ้งเตือน LINE, หรือ line_user_id เปลี่ยน (ลบ+เพิ่มเพื่อนใหม่) — ค่อยถาม user เป็นลำดับสุดท้าย
